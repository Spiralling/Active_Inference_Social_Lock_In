# Experiments

Every paper experiment, runnable through one entry point:

```
python scripts/run.py list                 # this table
python scripts/run.py run <name>           # run one experiment (with provenance)
python scripts/run.py run-all [--model M]  # run all / one model
```

Grouped by **model** -- phlogiston and cosmology are the two co-equal main models (phlogiston's canonical reference is `multiagent_topology`); `landscape` is a cosmology-adjacent group. Each run writes `results/<out_dir>/` containing `simulation_arrays.npz`, `summary.json`, the diagnostic figures, and a `manifest.json` recording the git SHA, environment, seeds, resolved params, and per-array hashes -- so any figure traces back to the exact code and configuration that produced it.
