# Independent packaging review

The review inspected `build_handoff.py`, `finalize_handoff.py`, the fresh-extraction checker, the package verifier, the staged handoff instructions and the included source/data inventory. It did not repeat the completed numerical audits or the separate agent's fresh-extraction tests.

The compact package contains the new and earlier figure inputs, plotting sources, producer dependencies, methods, results, captions and verification records. The optional Gaussian raw archive contains all 800 original NPZ chunks and their settings/manifests. Its root name matches the compact and earlier raw archives so that extracting them together supplies the documented reanalysis paths. The original seven figure assets are checked against their prior manifest. The inherited command dispatch points to the new producer.

One substantive verification gap was identified and resolved. The initial finalizer checked rendered assets and the pack PDF, while its claim covered the complete scientific and plotting payload. The revised finalizer first verifies that the staged manifest hash equals the manifest hash recorded by the fresh-extraction check. It then requires exact file-set equality and verifies every original file's size and SHA256 before adding any documentation or check records. This covers source, protocol, data reductions, CSV files and figures. The reviewer read and confirmed the revised checks.

The finalizer then adds the declared validation paragraph, portability script and check records, regenerates the complete payload manifest, and checks the final ZIP's CRCs and every manifested payload hash. The payload manifest excludes itself. The fresh-extraction report binds the original tested manifest; a separate external validation record binds the final archive. There is no circular hash dependency. A second run on an already modified payload is intentionally rejected rather than appending duplicate validation text.

No remaining material packaging omission or hash-logic defect was found. At review time, final packaging and the delivery commit were still pending. After committing, the parent must replace the external `delivery_commit: "pending"` value with the actual delivery commit before delivery. This review does not assert that those subsequent operations have already completed.
